# Mobile Sales Dashboard using Power BI
About the project -
I made this dashboard to analyze mobile phone sales data. The dataset has 320 transactions, 2K quantity sold and total sales of 64M. I used this to understand city-wise sales, model-wise performance and payment methods.

Key findings from the dashboard -
- iPhone SE is the top selling model followed by Galaxy Note 20 and OnePlus 9
- Credit Card is the most used payment method with 27.81% share
- Wednesday has the highest sales (11.1M), Sunday is lowest (7.9M)
- Mumbai has the highest number of customer ratings, followed by Rajkot and Patna
- Most customers have given 5 star rating, very few are below 4 star

Tools used -
Power BI Desktop, Power Query and DAX
Visuals used - Map chart, Line chart, Pie chart, Bar chart and Slicers for Month and Brand

Files -
- pbix file - complete interactive dashboard
- dashboard.png - preview image
